- 战斗中恢复在画面内直接拖动移动；左下八方向摇杆继续保留，两种操作可同时使用。
- 设置新增移动方式（混合／仅拖动／仅摇杆）、双指减速、双击 Bomb 与开发者模式，
  与自动射击一起保存在 `NSUserDefaults`，重开应用后保留。

- 游戏语言保持日文；设置中的“导出诊断日志”继续把报告写到 `Documents/Logs`
  并打开系统分享面板。

## 0.1.1（2）全屏布局与性能记录

在 iPad mini 5（iPad11,1）/ iOS 14.1 上安装 0.1.0 后确认总体可运行，但战斗卡顿。
导出的日志显示菜单中位数 59.9 FPS、战斗中位数 17.1 FPS，没有游戏错误、
GPU 读回或运行中着色器编译。

- 去掉底部控制栏，完整 640×480 双场地等比占满 iPad 4:3 屏幕。
- 左下半透明八方向摇杆，右下圆形 Z / X / S；右上齿轮与暂停图标。
- 自动射击移入设置；保留日志导出、后台暂停和按触点取消。
- iOS 每批顶点改用新的缓冲存储，避免反复修改已有绘制引用的存储而触发同步。
  原游戏逻辑、顶点内容与绘制顺序不变。该同步原因是待真机确认的假设。
- 每五秒记录渲染 FPS、逻辑频率以及逻辑／绘制／音频／提交／上传／呈现耗时。
  这些耗时区间有包含关系，不能直接相加。
- 摇杆死区、八方向、边界、反向对称与整圈 360 角度检查通过。
- Xcode 14 设备 ARM64 与模拟器编译通过；最低系统 14.0。
- 模拟器通过 900 帧剧情实战、蓄力／释放、暂停／恢复、存档读回和 900 帧录像
  回放（42,300 字段一致），并读完新增的性能记录与日志导出文件。

## 0.1.0（1）首个可安装版本

应用版本 0.1.0（1）；原作资源版本为日文 1.50a。参考设备为 iPad mini 5 / iOS 14，
通过兼容的安装器安装。技术范围：

- 建立原生 Xcode/CMake 工程，最低系统 14.0，设备 ARM64。
- 隔离 Web 主循环与存储，资源从只读应用包读取，存档写入 `Documents/TH09`。
- 存档通过临时文件、刷新和原子替换写入；切到后台保存成绩与设置。
- 保留 GLES3 渲染，正确绑定 UIKit 屏幕 framebuffer 与 renderbuffer。
- 32 位原版布局断言保留在 32 位构建；含主机指针的运行时对象允许 64 位布局。
- 触控取消按触点处理，独立维护后台、音频中断与弹窗的暂停原因。
- Z 长按优先于自动射击；释放 Z 后先产生释放帧，再继续自动射击。
- 本地双人模式的 UIKit 按钮固定归玩家一，避免与玩家二输入混用。
- 原版 EXE 图标提取脚本生成 iPad/iPhone AppIcon；生成图标属于私有资源。
- 设置中可导出诊断日志，通过系统分享面板存储或分享；保留本次与上次启动记录，
  包含版本指纹并遮盖私有路径。

## 范围

C++ 游戏主体、SDL3/GLES3 渲染、双场地横屏、日文资源、离线游戏、触控与手柄、
成绩与设置持久化、录像录制与回放。不包含语言切换与原生联机。原版 EXE 只作为
开发对照和图标提取输入，不进入应用。
